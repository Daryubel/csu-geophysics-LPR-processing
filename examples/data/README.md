# Packaged synthetic example

`ilmenite_demo.npz` is a small crop of a synthetic gprMax/LPR archive used in the associated manuscript.

## Source

- Dataset: synthetic ilmenite-bearing gprMax/LPR model
- Files copied: `legacy_originalTrace.dat`, `legacy_subtractedTrace.dat`, `legacy_tauTrace.dat`, `legacy_coherenceTrace.dat`, `legacy_alphaTrace.dat`
- Trace crop: indices 80–279 (200 traces)
- Time crop: samples 250–749 (500 samples)

The legacy files are stored as `(trace, time)`; the packaged arrays are saved as `(time, trace)`.

## Geometry

| field | value | note |
|---|---|---|
| `dt` | `9.77517e-11 s` | inferred from the 100 ns, 1024-sample export |
| `dx` | `0.02 m` | `#src_steps` / `#rx_steps` in the gprMax input |
| `x0` | `1.70 m` | `0.1 m + 80 * 0.02 m` |
| `t0` | `2.444e-8 s` | `250 * dt` |
| frequency | `5.0e8 Hz` | Ricker source in the gprMax input |

The source/receiver are zero-offset and move along the surface; the model grid in the original simulation is 10 m x 5 m with 0.003 m cells and a 100 ns time window.

## Arrays

| key | meaning |
|---|---|
| `data` | cropped raw B-scan (normalised per-array) |
| `diffraction_reference` | archived coherence-analysis diffraction export |
| `tau_reference` | archived local time-shift field (samples/trace) |
| `coherence_reference` | archived semblance/coherence export |
| `alpha_reference` | archived local amplitude correction |

The reference arrays are the original processing outputs; they were not generated by the `dwi` package.  They are included so that the inversion and property stages can be run independently of the built-in reconstruction.

## Citation

The synthetic model is distributed with the associated manuscript's data archive.  The processing exports are the `legacy_*Trace.dat` coherence-analysis products described in the manuscript and in He et al. (2023) / Zhang et al. (2023).
